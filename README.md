景行词库

## 📖 项目说明

 **Gboard** 是一款Android系统谷歌原生输入法，拥有现代化的UI和无联网日志的多方案隐私输入法。此项目是为新版谷歌输入法 **Gboard** 定制的自定义短语词库，通过自定义短语优化 **Gboard** 自带中文词库短板缺陷，从而提升输入效率。景行词库最初整理发布于2024年3月并于2025年12月迁移至GitHub。期间经历了20个大版本更迭、数10个子版本优化，最终趋于稳定性能与较好上手的平衡体验。此词库综合了日常生活场景中生活、科技、娱乐、游戏、文化、衣食住行等数10类词汇，以覆盖常用输入需求。  

- 词库文件为 **Gboard 导出的 `.zip` 格式**  
- 可在 Gboard 自带的导入入口直接导入使用  
- 该词库为自带词库的增强，不会与底层词库冲突  

---

## 🛠 支持方案

| 输入方案 | 描述 |
| :----: | ---- |
| 中文全拼 | 完整中文拼音输入 |
| 小鹤双拼 | 双拼方案，适合熟悉小鹤双拼的用户 |
| 自然码双拼 | 双拼方案，适合自然码输入习惯用户 |

## ✨ 亮点功能

### 1️⃣ Emoji 增强
- 在打字的同时，显示 Emoji 表情候选  
- 仅支持部分精选 Emoji，作为辅助亮点功能  

### 2️⃣ 前后缀和邮箱等便携输入
- 支持邮箱域名速打
- 支持软件、媒体、网址等常见前后缀

### 3️⃣ 词条过滤  
- 更纯净的词库，尽可能避免一些不合时宜的词语
